# すきまウォーカー 調整メモ

## 見た目

`Assets/Resources/SukimaWalkerVisualSettings.asset` を選択し、Inspectorで差し替えます。
シーン上のGameObjectではなく、Projectウィンドウ内のScriptableObjectアセット1箇所に集約しています。
再生中は `SukimaWalkerGame` がこのアセットを `Resources` から自動で読み込みます。

| 設定 | 変わるもの |
|---|---|
| Floor Sprite | 通路タイル |
| Wall Sprite | 壁タイル |
| Hole Sprite | 穴タイル |
| Goal Sprite | ゴールタイル |
| Character Up Sprite | 主人公が上向きの時 |
| Character Down Sprite | 主人公が下向きの時 |
| Character Left Sprite | 主人公が左向きの時 |
| Character Right Sprite | 主人公が右向きの時 |

未設定の場合は、仮の色付き四角で表示されます。

## 進行・演出タイミング

`Assets/Resources/SukimaWalkerPresentationSettings.asset` を選択し、Inspectorで調整します。
こちらもシーン上のGameObjectではなく、Projectウィンドウ内のScriptableObjectアセット1箇所です。

| 設定 | 変わるもの |
|---|---|
| Gameplay Inactivity Timeout Seconds | プレイ中に操作がない時、ステージセレクトへ戻るまでの秒数 |
| Select Idle Demo Delay Seconds | セレクト画面で放置デモが始まるまでの秒数 |
| Preview Pulse Speed | セレクト中サムネイルの動く速さ |
| Preview Pulse Amount | セレクト中サムネイルの動く大きさ |
| Idle Demo Cycle Seconds | 放置デモ中にフォーカスステージが切り替わる間隔 |
| Clear Return Delay Seconds | クリア後にセレクトへ戻るまでの待ち時間 |
| Completed Stage Tint | クリア済みステージカードの色 |
| Locked Stage Tint | 未クリアステージカードの色 |
| Idle Demo Clip | 後から差し替える放置デモ用AnimationClip |

## ステージセレクト

Unityで再生すると、最初にステージセレクトが表示されます。

| 表示 | 意味 |
|---|---|
| 小さな盤面プレビュー | そのステージの地形サムネイル |
| 下部の四角い星 | 難易度、1から5 |
| カード色の変化 | クリア済みかどうか |
| カーソル中の拡大縮小 | 選択中ステージのプレビューアニメーション |
| 右上のEボタン | エディターへ移動 |

ステージセレクトで一定時間操作しないと、フォーカス中のステージプレビューが周期的に切り替わります。
待機までの秒数や動き方は `SukimaWalkerPresentationSettings.asset` で調整できます。

## ステージ制作

Unityで再生するとステージセレクトが表示されます。右上の `E` ボタンでエディターへ移動します。

| エディター項目 | 変わるもの |
|---|---|
| ID / Title | ステージ保存名と管理名 |
| W / H | 盤面サイズ |
| *** | 難易度の星数、1から5 |
| Palette | 配置する地形、看板、主人公 |
| Direction | 看板の向き、主人公の初期方向 |
| Frame Min / Max | Frameの最小・最大サイズ |
| Save | `Application.persistentDataPath/stages` にJSON保存 |
| Test Play Current | 編集中ステージをそのままテストプレイ |

## プレイ中の操作

| 操作 | 結果 |
|---|---|
| Frame内部ドラッグ | Frameを1マス単位で移動 |
| Frame辺/角ドラッグ | Frameを1マス単位でリサイズ |
| Rキー または左上のRボタン | 即時リトライ |
| 最初のFrame操作 | 主人公が動き始める |
| 一定時間無操作 | ステージセレクトへ戻る |

## コア挙動の注意

- 穴は常に有効です。Frameで覆っても無効化されません。
- Frameは主人公を押しません。主人公が次に進むセルがFrame外なら反転します。
- Frameは、Frame内にいた主人公や看板を置き去りにする形では動けません。
- 看板はFrameの辺に押された時だけ1マス動きます。穴へ押されると破棄されます。
- 隣接看板は、押す方向の奥から手前へ順番に処理されます。
